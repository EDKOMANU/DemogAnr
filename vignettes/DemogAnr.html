Demographic Analysis with DemogAnr

Why this package

Applied demographic work is still carried out largely in spreadsheets: a life table here, a total fertility rate there, an age distribution split into single years. Spreadsheets are visual and familiar, but their formulas are invisible until each cell is inspected, and reproducing an analysis a year later often means rebuilding it from memory.

DemogAnr aims to make the standard textbook methods directly usable in R. Three commitments shape it:

  • Textbook notation. Rates are requested by their conventional abbreviations ("CBR", "TFR", "CDR"), and life-table columns are named as they appear in Preston, Heuveline and Guillot (2001): nMx, nax, nqx, lx, dx, Lx, Tx, ex.
  • Readable output. Functions return a classed object whose print method lays the numbers out as a labelled table, so you see what you would write in a report rather than a nested list.
  • A consistent API. Every function takes a data frame plus character column names.

Wherever possible, the examples below reproduce a published worked example, so that you can follow the calculation in the textbook alongside the code.

1. Rates: fertility and mortality

dem.fert() computes the crude birth rate, general fertility rate, age-specific rates and the total fertility rate. Here is the Bangladesh 1974 schedule from United Nations Manual X, Chapter II, whose reported total fertility rate is 4.83.

bangladesh <- data.frame(
  age         = c("15-19","20-24","25-29","30-34","35-39","40-44","45-49"),
  women       = c(3014706, 2653155, 2607009, 2015663, 1771680, 1479505, 1135129),
  live_births = c(320406, 609269, 561494, 367833, 237297, 95357, 38125),
  population  = 71315944
)
fert <- dem.fert(bangladesh, type = "all", age_col = "age",
                 population_col = "population", women_col = "women",
                 births_col = "live_births", graph = FALSE)
fert$results$TFR
#> [1] 4.828819

dem.cdr() does the same for mortality. Preston et al. (2001, Box 1.2) report a crude death rate of 11.47 per 1000 for Sweden in 1988:

sweden88 <- data.frame(population = 8438477, deaths = 96756)
dem.cdr(sweden88, type = "CDR", population_col = "population",
        deaths_col = "deaths", graph = FALSE)$results$CDR
#> [1] 11.46605

Childhood and maternal mortality are available through dm.chm() and dem.mmr().

3. Multiple decrement and cause-deleted tables

When deaths are classified by cause, multiple_decrement() distributes the life-table deaths across causes. This reproduces Preston et al. (2001) Box 4.1 for US females in 1991: of 100,000 newborns, 21,205 (21.2%) would eventually die of neoplasms.

us91 <- data.frame(
  Age  = c(0, 1, seq(5, 85, 5)),
  Dall = c(15758, 3169, 1634, 1573, 3955, 4948, 6491, 9428, 12027, 15543,
           19264, 25384, 37211, 59431, 88087, 114693, 143554, 164986, 320578),
  Dneo = c(63, 275, 268, 217, 318, 467, 856, 1924, 3532, 5958,
           8434, 11673, 17078, 25263, 33534, 36695, 36571, 30220, 32739),
  lx   = c(100000, 99217, 99050, 98959, 98870, 98637, 98379, 98070, 97653,
           97083, 96289, 95008, 93018, 89882, 85249, 78711, 69618, 57486, 41756),
  nqx  = c(0.00783, 0.00168, 0.00092, 0.00090, 0.00236, 0.00262, 0.00314,
           0.00425, 0.00584, 0.00818, 0.01330, 0.02095, 0.03371, 0.05155,
           0.07669, 0.11552, 0.17427, 0.27363, 1.00000),
  nax  = c(0.152, 1.605, 2.275, 2.843, 2.657, 2.547, 2.550, 2.616, 2.677,
           2.685, 2.681, 2.655, 2.647, 2.646, 2.631, 2.628, 2.618, 2.570, 6.539)

cause_deleted_lt() answers the companion question: what would life expectancy be if the cause were eliminated? The deletion assumption is yours to choose through method.

cd <- cause_deleted_lt(us91, age = "Age", cause = "Dneo", deaths = "Dall",
                       lx = "lx", nqx = "nqx", nax_all = "nax", graph = FALSE)
c(e0 = cd$e0, without_neoplasms = cd$e0_deleted, gain = cd$gain)
#>                e0 without_neoplasms              gain 
#>         78.920244         82.431586          3.511342

Both functions accept either a population column, from which the life table is built, or a ready-made table through lx, nqx and nax_all.

4. Reproduction and the stable population

reproduction() computes the gross and net reproduction rates. For US females in 1991 (Preston et al. 2001, Box 5.5) the published values are GRR 1.013 and NRR 0.995.

us1991 <- data.frame(
  age   = seq(10, 45, 5),
  fbir  = c(5816, 253979, 532712, 596823, 431694, 162005, 25531, 829),
  women = c(8620, 8371, 9419, 10325, 11125, 10344, 9496, 7188) * 1000,
  nLx   = c(494603, 493804, 492552, 491138, 489356, 486941, 483577, 478475)
)
r <- reproduction(us1991, age = "age", births = "fbir", women = "women",
                  nLx = "nLx", radix = 1e5, fraction_female = 1, graph = FALSE)
c(GRR = r$GRR, NRR = r$NRR)
#>       GRR       NRR 
#> 1.0132277 0.9953345

stable_population() solves Lotka’s equation for the intrinsic growth rate by Coale’s iterative procedure. Preston et al. (2001, Box 7.1) obtain \(r = 0.01424\) for Egypt in 1997:

egypt <- data.frame(
  age = seq(15, 45, 5),
  Lx  = c(4.66740, 4.63097, 4.58518, 4.53206, 4.46912, 4.39135, 4.28969),
  ma  = c(0.00567, 0.06627, 0.11204, 0.07889, 0.05075, 0.01590, 0.00610)
)
sp <- stable_population(egypt, age = "age", asfr = "ma", nLx = "Lx",
                        radix = 1, fraction_female = 1, graph = FALSE)
c(r = sp$r, b = sp$b, d = sp$d, NRR = sp$NRR)
#>          r          b          d        NRR 
#> 0.01424406 0.04963294 0.03538888 1.52741373

5. Indirect estimation

Where registration is incomplete, fertility and child mortality are estimated indirectly. pf_ratio() implements the Brass P/F ratio method; on the Manual X Bangladesh 1974 example the adjustment factor is 1.500 and the adjusted total fertility rate 7.24.

bd <- data.frame(
  age    = seq(15, 45, 5),
  women  = c(3014706, 2653155, 2607009, 2015663, 1771680, 1479505, 1135129),
  ceb    = c(1160919, 4901382, 9085852, 9910256, 10384001, 9164329, 6905673),
  births = c(320406, 609269, 561494, 367833, 237297, 95357, 38125)
)
pf <- pf_ratio(bd, age = "age", women = "women", ceb = "ceb",
               births = "births", graph = FALSE)
c(K = pf$K, TFR = pf$TFR, TFR_adjusted = pf$TFR_adjusted)
#>            K          TFR TFR_adjusted 
#>     1.499137     4.828819     7.239061

chm_brass() estimates child mortality from children ever born and children surviving, by the Brass-Trussell method. It returns \(q(x)\) with the calendar date each estimate refers to.

panama <- data.frame(
  women = c(2695, 2095, 1828, 1605, 1362, 1128, 930),
  ceb   = c(557, 2633, 4757, 6085, 6722, 6367, 5276),
  cd    = c(40, 130, 312, 435, 636, 686, 689)
)
est <- chm_brass(panama, women_col = "women", ceb_col = "ceb",
                 cd_col = "cd", model = "west", survey_year = 1976.7)
est$qx[est$x == 5]
#> [1] 0.0717859

On its own that is a set of probabilities, not a life table. model_lifetable() finishes the job: give it the estimated \(q(5)\) and it returns the model table matching it, in any of the four Coale-Demeny families or the five United Nations patterns.

fitted <- model_lifetable("west", sex = "male", q5 = est$qx[est$x == 5],
                          graph = FALSE)
fitted$metrics$LifeExpectancyAtBirth
#> [1] 62.85683

The same child mortality implies different adult mortality in different families, which is why the family has to be chosen rather than assumed:

sapply(c("CD_West", "CD_North", "CD_South", "CD_East"), function(f)
  model_lifetable(f, sex = "male", q5 = est$qx[est$x == 5],
                  graph = FALSE)$metrics$LifeExpectancyAtBirth)
#>  CD_West CD_North CD_South  CD_East 
#> 62.85683 63.79673 67.77688 63.77914

The alternative to picking a family is the Brass relational logit model, which fits a two-parameter transformation of a standard rather than choosing from a grid. brass_logit() estimates the level \(\alpha\) and the age-pattern slope \(\beta\); complete = TRUE carries them through to the life table they imply.

fit <- brass_logit(data.frame(age = est$x, qx = est$qx),
                   qx_col = "qx", age_col = "age", standard = "African",
                   complete = TRUE)
round(fit$coefficients, 4)
#>     (Intercept) standard_logits 
#>         -0.7556          0.6685
fit$lifetable$metrics$LifeExpectancyAtBirth
#> [1] 68.5678

brass_lifetable() can also be used on its own, with no data at all: give it \(\alpha\) and \(\beta\) directly, or a target level to solve for.

brass_lifetable(target_e0 = 60, standard = "African",
                graph = FALSE)$brass$alpha
#> [1] -0.5356655

Adult mortality is estimated the same way round. Where chm_brass() uses a mother’s report on her children, orphanhood() uses children’s reports on their mother, and returns female survivorship from age 25 with the number of years before the survey each estimate refers to. On the Manual X Bolivia 1975 example:

6. Completeness of death registration

A life table built from registered deaths is only as good as the registration. Where it is incomplete – the normal case wherever civil registration is still developing – the table understates mortality, and the first task is to find out by how much. The death distribution methods do that from two censuses and the deaths recorded between them.

d <- data.frame(
  age = c(0, seq(5, 85, 5)),
  n1  = c(41255, 36289, 31948, 28121, 24743, 21758, 19116, 16770, 14677,
          12798, 11094, 9527, 8060, 6659, 5298, 3970, 2706, 2614),
  n2  = c(52973, 46596, 41022, 36108, 31770, 27938, 24545, 21533, 18846,
          16433, 14245, 12233, 10349, 8550, 6802, 5098, 3475, 3356),
  dth = c(516, 134, 126, 123, 126, 136, 154, 184, 229, 294, 385, 508,
          668, 865, 1084, 1282, 1380, 2833)
)
g <- ggb(d, age = "age", pop1 = "n1", pop2 = "n2", deaths = "dth",
         t1 = 2000, t2 = 2010, graph = FALSE)
c(completeness = g$completeness, coverage_ratio = g$coverage_ratio)
#>   completeness coverage_ratio 
#>      0.6995644      1.0009353

These deaths were registered at 70 per cent completeness, and the generalized growth balance recovers it. seg() estimates the same quantity by synthetic extinct generations, and ggb_seg() runs the two in sequence, using the first to correct for the censuses covering the population differently before the second is applied.

c(GGB = g$completeness,
  SEG = seg(d, "age", "n1", "n2", "dth", 2000, 2010, graph = FALSE)$completeness,
  combined = ggb_seg(d, "age", "n1", "n2", "dth", 2000, 2010,
                     graph = FALSE)$completeness)
#>       GGB       SEG  combined 
#> 0.6995644 0.7014690 0.7044130

Neither method should be used without looking at its diagnostic plot first: plot() on a ggb() result shows the fitted line, which should be straight, and on a seg() result the age-specific ratios, which should be flat. A curve in either is a sign that the assumptions – a closed population, registration equally complete at every age – do not hold.

8. Projection

math_project() performs deterministic subnational projection by six methods (linear, exponential, geometric, constant-share, shift-share, share-of-growth), optionally constraining units to a parent control total.

cohort_component() performs the full age–sex projection through a Leslie matrix. It reproduces Preston et al. (2001) Box 6.1 for Swedish females exactly:

sweden <- data.frame(
  Age = c(seq(0, 80, 5), 85),
  N93 = c(293395, 248369, 240012, 261346, 285209, 314388, 281290, 286923,
          304108, 324946, 247613, 211351, 215140, 221764, 223506, 183654,
          141990, 112424),
  Lx  = c(497487, 497138, 496901, 496531, 495902, 495168, 494213, 492760,
          490447, 486613, 480665, 471786, 457852, 436153, 402775, 350358,
          271512, 291707),
  Fx  = c(0, 0, 0, 0.0120, 0.0908, 0.1499, 0.1125, 0.0441, 0.0074, 0.0003,
          rep(0, 8))
)
cc <- cohort_component(sweden, age = "Age", population = "N93", nLx = "Lx",
                       asfr = "Fx", steps = 2, graph = FALSE)
round(cc$totals)
#>      y0      y5     y10 
#> 4397428 4449570 4478712

project_population() carries uncertainty through the demographic balancing equation \(g = b - d + m\), drawing each component from a distribution that you specify.

pp <- project_population(region2000[1:4, ],
        base_year = 2000, future_year = 2010,
        region_var = "Country", subregion_var = "Region",
        base_pop_var = "base_pop", birth_rate_var = "cbr",
        death_rate_var = "cdr", net_migration_var = "nmr",
        num_samples = 500, graph = FALSE)
subset(pp, year == 2010)
#>    region     subregion year   lower  median    mean   upper
#> 11  Ghana       Western 2010 1790114 1866938 1867967 1957554
#> 22  Ghana       Central 2010 1826615 1911712 1912354 2002872
#> 33  Ghana Greater Accra 2010 3779998 3930477 3935194 4087288
#> 44  Ghana         Volta 2010 1240419 1297273 1298658 1358384

Each trajectory draws its rates once and holds them across the horizon, so the band widens with the projection. Supplying death_dist, birth_dist or migration_dist replaces the defaults with your own sampler.

project_population() can also carry an assumed trend rather than holding each rate constant. birth_target, death_target and migration_target give the value a component is heading towards by future_year (a single number, or a column of per-region targets), and path chooses whether it gets there "linear"ly or "exponential"ly. Each trajectory then draws both a start rate and an end rate and interpolates between them, so the trend and the uncertainty about it travel together; target_cv sets the spread around the target and is normally wider than cv, since a rate two decades out is less certain than today’s:

pp_trend <- project_population(region2000[1:4, ],
        base_year = 2000, future_year = 2030,
        region_var = "Country", subregion_var = "Region",
        base_pop_var = "base_pop", birth_rate_var = "cbr",
        death_rate_var = "cdr", net_migration_var = "nmr",
        birth_target = 0.024, death_target = 0.008,
        cv = 0.05, target_cv = 0.20,
        num_samples = 500, graph = FALSE)
subset(pp_trend, year == 2030)
#>     region     subregion year   lower  median    mean   upper
#> 31   Ghana       Western 2030 2581116 2853365 2876062 3207361
#> 62   Ghana       Central 2030 2238803 2491521 2508962 2776886
#> 93   Ghana Greater Accra 2030 6216186 6801402 6868495 7610837
#> 124  Ghana         Volta 2030 1386091 1532897 1540571 1712578

Omitting the targets holds every rate at its base-year value and reproduces the earlier, constant-rate behaviour exactly.

calibrate_regions() addresses a different problem: not projecting each region, but disaggregating a national projection that is already settled down to regions, raking the regions back onto the national control total in every year. Where project_population() lets each region find its own total, calibrate_regions() takes the national trajectory as given and asks only how it is shared out, which is the sequence used in official projection work (first agree the national numbers, then split them regionally):

base_total <- sum(region2000$base_pop)
national <- data.frame(
  year  = seq(2000, 2020, 5),
  total = round(base_total * exp(0.025 * seq(0, 20, 5)))
)
cal <- calibrate_regions(region2000,
        region_col = "Region", pop_col = "base_pop",
        national = national, year_col = "year", total_col = "total",
        deviation = 0.08, num_samples = 500, graph = FALSE)
cal$check
#>   year regional_sum  control difference
#> 1 2000     18912079 18912079          0
#> 2 2005     21430193 21430193          0
#> 3 2010     24283590 24283590          0
#> 4 2015     27516913 27516913          0
#> 5 2020     31180747 31180747          0

Each region is allowed to deviate from the national profile by a mean-preserving lognormal (here with coefficient of variation 0.08), phased in over the horizon, and then raked back onto the national total; cal$check confirms the regional sum reproduces the control total in every year. With no deviation the function reduces to the ordinary constant-share allocation and every raking factor is 1.

9. Data quality, smoothing and graduation

Reported ages should be screened before analysis. whipple() and myers() measure digit preference, and un_age_sex_accuracy() combines age and sex ratios into the United Nations joint index.

males <- subset(ghpop2021, Sex == "Male")
w <- whipple(males, age_col = "Age", pop_col = "Population", graph = FALSE)
w$index
#> [1] 115.2924

Where screening shows misreporting, the age distribution can be smoothed. The decision is not automatic. Smoothing assumes that people were reported at the wrong age rather than missed, so the deficit in an under-enumerated age group is spread to its neighbours; and genuine irregularities in the age structure are erased together with the errors.

The 1960 census of Ghana, the example Kpedekpo (1982) uses for the United Nations index, shows the saw-tooth pattern of age misreporting. The female age ratios fall to 84 and 82 at 10-14 and 15-19 and rise to 113 and 108 at 20-24 and 25-29: an excess of women at 20-29 at the expense of 10-19. smooth_ages() applies the five formulas of the Census Bureau’s AGESMTH workbook. Carrier-Farrag, Karup-King-Newton and Arriaga only redistribute people between the two halves of each ten-year group, so they cannot repair a transfer between ten-year groups; the United Nations formula and Arriaga’s strong smoothing reach across them. The age ratio score, the mean absolute deviation of the age ratios from 100, falls accordingly:

ghana1960 <- data.frame(
  age = c("0-4","5-9","10-14","15-19","20-24","25-29","30-34","35-39",
          "40-44","45-49","50-54","55-59","60-64","65+"),
  females = c(654258, 503070, 323460, 265534, 322576, 306329, 245883,
              179182, 145572, 95590, 81715, 48412, 54572, 100392)
)
methods <- c("carrier_farrag", "kkn", "arriaga", "united_nations", "strong")
scores <- sapply(methods, function(m) {
  smooth_ages(ghana1960, "age", "females", method = m,
              graph = FALSE)$score_smoothed
})
reported <- smooth_ages(ghana1960, "age", "females",
                        graph = FALSE)$score_reported
round(c(reported = reported, scores), 2)

graduate() then splits the smoothed groups into single years of age. With Sprague’s multipliers, the default, the single years of each group add back to that group exactly:

g <- graduate(s$table, "age", "smoothed", graph = FALSE)
head(g$table)
#>   age population
#> 1   0   143539.1
#> 2   1   137178.1
#> 3   2   130813.9
#> 4   3   124487.5
#> 5   4   118239.4
#> 6   5   112110.4
max(abs(g$groups$difference))
#> [1] 5.820766e-11

Single years can also be smoothed directly. smooth_single_ages() applies the weighted moving average of the Census Bureau’s POP1SM workbook, which removes the heaping on ages ending in 0 and 5 from the Ghana 2021 males:

s1 <- smooth_single_ages(males, "Age", "Population", graph = FALSE)
c(Whipple_reported = s1$whipple_reported,
  Whipple_smoothed = s1$whipple_smoothed)
#> Whipple_reported Whipple_smoothed 
#>        115.29238         99.85183

smam() computes the singulate mean age at marriage from proportions single by age. Preston et al. (2001, Box 4.4) report 25.0 years for Turkish males in 1990:

turkey <- data.frame(
  age    = seq(15, 50, 5),
  men    = c(3165061, 2581153, 2435765, 2096899, 1784121, 1418784,
             1111113, 980115),
  single = c(3030203, 1853222, 629077, 180767, 77134, 43412, 28627, 22527)
)
smam(turkey, age = "age", single = "single", total = "men")$SMAM
#> [1] 24.98756

10. Figures

Core functions take graph = TRUE, attaching a ggplot2 figure retrievable with plot(). A standalone pyramid() draws a population pyramid.

g <- within(ghpop2021, grp <- ifelse(Age >= 80, "80+",
            paste0((Age %/% 5) * 5, "-", (Age %/% 5) * 5 + 4)))
pyr <- aggregate(Population ~ grp + Sex, data = g, FUN = sum)
pyramid(pyr, age_col = "grp", sex_col = "Sex", count_col = "Population",
        title = "Ghana, 2021")
